## 2024-05-18 - [Optimize Clickhouse Inserts]
**Learning:** Analytics log serializers inside tight loops were generating a new String via `serde_json::to_string` on every iteration before writing to a `String` buffer (then converted to `Vec<u8>` inside `reqwest`).
**Action:** When converting multiple items into a single payload buffer in `reqwest`, allocate the `Vec<u8>` directly with capacity and stream directly using `serde_json::to_writer` to eliminate excessive intermediate heap allocations per record. Note: Beware `serde_json::to_writer` doesn't always automatically push error handling to truncation—if the buffer falls out of scope via a return, explicit truncation before return is redundant.

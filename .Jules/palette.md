## 2023-10-27 - Icon-only button accessibility in Sidebar/Panels
**Learning:** When UI components like sidebars collapse and visually hide text labels, or when using standard icon-only buttons (like 'Clear Search', 'Collapse Sidebar', 'Hide Filters'), they often rely solely on the `title` attribute for tooltip hover states. However, `title` is not reliably announced by all screen readers. They need explicit `aria-label`s mapping to those same translated strings to guarantee accessibility.
**Action:** Always pair a `title` attribute with an explicit `aria-label` (using the same translated text) on any interactive element (`<button>`, `<a>`) that lacks visible text content, especially within highly interactive shell components like `nav-sidebar` and `filter-panel`.
